# How A+ scoring works

Short version: each A+ exam gives you a scaled score from 100 to 900. You pass Core 1 (220-1201) with **675** or more and Core 2 (220-1202) with **700** or more, and you need both passes for the certification. CompTIA does not tell you how many questions you need right, how many you got wrong, or how questions are weighted. Your score report lists the objectives you missed questions on, which is the most useful part.

## The scaled score

CompTIA's help center says its exams use a mathematical algorithm to calculate a **scaled score**. The scaled score is derived from what would otherwise be a percentage score, and passing scores are set through statistical analysis.

| | Core 1 (220-1201) | Core 2 (220-1202) |
|---|---|---|
| Scale | 100 to 900 | 100 to 900 |
| Passing score | 675 | 700 |

Because of the scaling, you cannot turn 675 or 700 into "you need 75% right". As we understand it (our reading, not a CompTIA statement), different exam forms can differ slightly in difficulty, and scaling is how CompTIA makes a pass mean the same thing on every form. CompTIA states that it does not disclose the number of questions required to pass. It also means a 700 on Core 1 and a 700 on Core 2 are not directly comparable: each exam is scaled separately and has its own cut score.

## Each core is scored on its own

There is no combined A+ score. Core 1 and Core 2 are separate exams, scored separately, each with its own pass or fail. A strong Core 1 score does not make up for a weak Core 2, and you can pass one and retake the other.

## What CompTIA does not publish

- The number of correct answers needed to pass either exam.
- The number of questions you answered incorrectly.
- How performance-based or drag-and-drop questions are weighted compared with multiple-choice questions.
- Pass rates.

Anything you read about "PBQs are worth X points" or "you need 80% on Core 2" is guesswork.

## What your score report shows

After each exam you receive a score report. It does not show which questions you got wrong or how many. It does list the **exam objectives associated with questions you answered incorrectly**. That list is a study plan: if you need to retake, start with those objectives, using the matching domain pages for [Core 1](core-1/README.md#core-1-domains-and-weights) or [Core 2](core-2/README.md#core-2-domains-and-weights).

## Answer every question

An unanswered question cannot earn credit. If you are running out of time, make your best guess on everything left rather than leaving blanks.

## What practice score to aim for

This is our guidance, since CompTIA publishes no conversion from practice scores. Because the real passing point is not published as a percentage, aim to score **comfortably above 80%** on practice items you have not seen before, under time pressure, for the core you are about to sit. Be consistent across domains rather than very strong in one and weak in another. On Core 1, a weak Troubleshooting score (28%) can sink an otherwise good attempt; on Core 2, Operating Systems and Security are 28% each, so a gap in either is costly. Core 2's higher passing score is one more reason not to aim for a bare pass.

Use the score tables at the end of each domain page to track this, and a full timed run such as the [free CompTIA A+ practice test on PrepClubs](https://prepclubs.com/free-practice-tests/a-plus?utm_source=github&utm_medium=referral&utm_campaign=study-notes&utm_content=a-plus) to check pace.

## If you do not pass

The retake rules apply to each exam separately.

- There is no waiting period between your first and second attempt.
- Before a third or later attempt, you must wait at least 14 calendar days from your last attempt.
- Each attempt is paid in full; CompTIA offers no free retests.
- You cannot retake an exam you have already passed under the same exam code without CompTIA's consent.

Take a day off, then rebuild your plan around the objectives on your score report before booking again. The [study plans](study-plans.md) page explains how to review misses.
