# Core 2 (220-1202) overview

Core 2 is the software and procedures half of CompTIA A+ V15: Windows, macOS and Linux, command-line tools, security settings and malware removal, troubleshooting operating systems and apps, and the professional side of support work such as documentation, change management, backups, safety, scripting, remote access and AI basics. You need Core 2 and [Core 1 (220-1201)](../core-1/README.md), from the same version, to earn A+. All exam facts here come from CompTIA's Core 2 V15 page and the official 220-1202 objectives. The practice items are original.

## Core 2 at a glance

| Item | Detail |
|---|---|
| Exam code | 220-1202 (A+ Core 2, V15) |
| Launched | March 25, 2025 |
| Retires | Usually three years after launch (CompTIA estimates 2028) |
| Questions | A maximum of 90 |
| Question types | Multiple-choice (single and multiple response), drag-and-drop, performance-based |
| Time | 90 minutes |
| Passing score | 700 on a scale of 100 to 900 |
| Recommended experience | 12 months of hands-on experience in an IT support specialist job role |
| Languages | English, German, Japanese |
| Delivery | Pearson VUE test center, or online with OnVUE |
| Pairs with | Core 1 (220-1201). Both must be from the same version |

Note the passing score: 700, higher than Core 1's 675. The rules that apply to both cores (order, retakes, renewal) are on [How CompTIA A+ works](../a-plus-overview.md).

The weights are CompTIA's. The question counts are our arithmetic (weight times 90, rounded down); CompTIA does not publish how many questions come from each domain, and a real exam can differ.

The weights are more even than on Core 1. Operating Systems and Security together are more than half the exam, so no domain can be skipped. Operational Procedures, at 21%, looks like soft skills but is full of exact lists: backup types, safety procedures, change management steps and policy terms.

## What Core 2 covers

- **Operating Systems:** OS types, installs and upgrades, Windows editions, Windows tools and command-line tools, Windows settings and networking, macOS and Linux desktop features, installing applications, and cloud-based productivity tools.
- **Security:** security measures, Windows security settings, wireless security protocols, malware types and removal, social engineering, workstation hardening, mobile device security, data destruction, SOHO network security, and browser security settings.
- **Software Troubleshooting:** common Windows issues, mobile OS and app issues, mobile security issues, and PC security issues.
- **Operational Procedures:** documentation and support systems, change management, backup and recovery, safety, environmental controls, privacy, licensing and policy, communication and professionalism, scripting basics, remote access technologies, and basic AI concepts.

## How the Core 2 questions work

- **Pick the tool.** Many Operating Systems questions describe a task and ask which Windows tool or command does it. Know what each one is for, not only its name.
- **Pick the setting.** Security and SOHO questions give a goal (stop guest access, encrypt a laptop, secure Wi-Fi) and ask for the right setting or protocol.
- **Order the steps.** The malware removal procedure in objective 2.6 is a numbered list in the objectives, a natural fit for drag-and-drop and PBQs.
- **Symptom first.** Software Troubleshooting stems describe what the user sees and ask for the cause or the fix.
- **Not exhaustive.** The objectives' example lists are the minimum; other examples can appear.

## How to study Core 2

Our suggested order, built on the weights:

1. **Take the [diagnostic](../diagnostic.md)** to find where you already stand.
2. **Start with Domain 1, Operating Systems (28%).** Open the Windows tools as you read about them: Task Manager, Event Viewer, Disk Management, Device Manager, the Control Panel and Settings. Run each command-line tool in the objectives at least once.
3. **Then Domain 2, Security (28%).** Learn the malware removal steps in order, the wireless security protocols, and which Windows feature handles which job (encryption, firewall, account control).
4. **Then Domain 3, Software Troubleshooting (23%).** It builds directly on Domains 1 and 2. Make a symptom and fix table for each objective, 3.1 to 3.4.
5. **Then Domain 4, Operational Procedures (21%).** Make flash cards for the lists: backup methods, change management, safety, and the communication rules.
6. **Do the practice items** at the end of each domain page and score yourself honestly.
7. **Finish with timed runs** so about one minute per question feels normal.

If you are new to IT, give each step a week or more. See [study plans](../study-plans.md) for day-by-day versions.
