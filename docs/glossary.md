# Glossary

Short definitions of terms that come up on Core 1 (220-1201) and Core 2 (220-1202). Most acronyms here appear in CompTIA's official acronym list, which is the same for both exams, and in the objectives. Each entry links to the domain where it matters most. Where the official list's expansion differs from common usage, we give the standard meaning.

| Term | Meaning |
|---|---|
| AAA | Authentication, authorization and accounting: proving identity, granting rights, recording activity ([Core 2, Domain 2](core-2/2-security.md)) |
| ACL | Access control list: rules that allow or deny traffic or access to a resource |
| ADF | Automatic document feeder: the tray that feeds pages into a scanner or copier ([Core 1, Domain 3](core-1/3-hardware.md)) |
| AES | Advanced Encryption Standard, the symmetric cipher used by WPA2 and WPA3 |
| APFS | Apple File System, the default file system for current macOS ([Core 2, Domain 1](core-2/1-operating-systems.md)) |
| APIPA | Automatic Private IP Addressing: a Windows client gives itself a 169.254.x.x address when it cannot reach a DHCP server ([Core 1, Domain 2](core-1/2-networking.md)) |
| ARM | A RISC processor architecture common in phones, tablets and many laptops ([Core 1, Domain 3](core-1/3-hardware.md)) |
| ATX | Advanced Technology Extended, the standard full-size motherboard and power supply form factor |
| AUP | Acceptable use policy: rules for how staff may use company systems ([Core 2, Domain 4](core-2/4-operational-procedures.md)) |
| BIOS | Basic Input/Output System: legacy firmware that tests hardware and starts the boot process |
| BSOD | Blue Screen of Death: the Windows stop error screen ([Core 2, Domain 3](core-2/3-software-troubleshooting.md)) |
| BYOD | Bring your own device: staff use personal devices for work, usually under MDM policy ([Core 1, Domain 1](core-1/1-mobile-devices.md)) |
| CMOS | Complementary metal-oxide semiconductor: the battery-backed chip that keeps firmware settings and the clock; a dead CMOS battery resets the date and time ([Core 1, Domain 5](core-1/5-hardware-and-network-troubleshooting.md)) |
| CNAME | Canonical name: a DNS record that points one name at another name |
| Container | A lightweight package of an app and its dependencies that shares the host OS kernel ([Core 1, Domain 4](core-1/4-virtualization-and-cloud-computing.md)) |
| DDR | Double data rate: RAM that transfers data on both edges of the clock signal (DDR4, DDR5) ([Core 1, Domain 3](core-1/3-hardware.md)) |
| DHCP | Dynamic Host Configuration Protocol: hands out IP address, mask, gateway and DNS settings automatically; UDP 67 and 68 ([Core 1, Domain 2](core-1/2-networking.md)) |
| DIMM | Dual in-line memory module: the desktop RAM stick |
| DKIM | DomainKeys Identified Mail: a DNS-published key that lets receivers verify a message was signed by the sending domain |
| DMARC | Domain-based Message Authentication, Reporting, and Conformance: a DNS policy telling receivers what to do when SPF or DKIM checks fail |
| DNS | Domain Name System: resolves names to IP addresses; port 53 ([Core 1, Domain 2](core-1/2-networking.md)) |
| DoS, DDoS | Denial of service: an attack that overwhelms a service; distributed when it comes from many systems at once |
| DSL | Digital subscriber line: internet service over telephone copper |
| ECC | Error-correcting code: RAM that detects and fixes single-bit errors, common in servers ([Core 1, Domain 3](core-1/3-hardware.md)) |
| EDR | Endpoint detection and response: software that monitors endpoints for threats and helps respond to them ([Core 2, Domain 2](core-2/2-security.md)) |
| EFS | Encrypting File System: Windows file and folder encryption tied to the user account |
| ESD | Electrostatic discharge: static that can damage components; prevented with an antistatic strap and mat ([Core 2, Domain 4](core-2/4-operational-procedures.md)) |
| EULA | End-user license agreement: the terms that come with software |
| exFAT | A Microsoft file system for flash drives that supports files over 4 GB and works across Windows and macOS |
| FAT32 | 32-bit File Allocation Table: an older, widely compatible file system with a 4 GB maximum file size |
| FTP | File Transfer Protocol: unencrypted file transfer; ports 20 and 21 |
| GFS | Grandfather-father-son: a backup rotation of daily, weekly and monthly sets ([Core 2, Domain 4](core-2/4-operational-procedures.md)) |
| GPT | GUID Partition Table: the modern partition scheme used with UEFI; supports large disks and many partitions |
| HDMI | High-Definition Multimedia Interface: digital video and audio connector ([Core 1, Domain 3](core-1/3-hardware.md)) |
| HTTPS | HTTP Secure: web traffic encrypted with TLS; port 443 |
| Hypervisor | Software that runs virtual machines. Type 1 runs directly on the hardware; Type 2 runs on top of a host OS ([Core 1, Domain 4](core-1/4-virtualization-and-cloud-computing.md)) |
| IaaS | Infrastructure as a service: the provider supplies virtual servers, storage and networks; you manage the OS and up ([Core 1, Domain 4](core-1/4-virtualization-and-cloud-computing.md)) |
| IMAP | Internet Message Access Protocol: reads mail kept on the server; port 143 ([Core 1, Domain 2](core-1/2-networking.md)) |
| IOPS | Input/output operations per second: a measure of storage performance |
| IPS (display) | In-plane switching: an LCD panel type with wide viewing angles and good color ([Core 1, Domain 3](core-1/3-hardware.md)) |
| LDAP | Lightweight Directory Access Protocol: queries directory services such as user accounts; port 389 |
| MAC address | Media access control address: the hardware address of a network interface |
| MBR | Master Boot Record: the legacy partition scheme, limited to four primary partitions and 2 TB disks |
| MDM | Mobile device management: central enrollment, policy and remote wipe for phones and tablets ([Core 1, Domain 1](core-1/1-mobile-devices.md)) |
| MFA | Multifactor authentication: two or more factor types, such as a password plus a code from a phone ([Core 2, Domain 2](core-2/2-security.md)) |
| MFP | Multifunction printer: prints, scans, copies and often faxes ([Core 1, Domain 3](core-1/3-hardware.md)) |
| MMC | Microsoft Management Console: the Windows host for snap-ins such as Device Manager and Event Viewer ([Core 2, Domain 1](core-2/1-operating-systems.md)) |
| MX | Mail exchanger: the DNS record that names a domain's mail server |
| NAS | Network-attached storage: a file storage device on the network (the official list also uses NAS for network access server) |
| NAT | Network address translation: maps private internal addresses to a public address |
| NFC | Near-field communication: very short-range wireless used for tap-to-pay and pairing ([Core 1, Domain 1](core-1/1-mobile-devices.md)) |
| NIC | Network interface card: the wired or wireless network adapter |
| NTFS | New Technology File System: the main Windows file system, with permissions, compression and encryption ([Core 2, Domain 1](core-2/1-operating-systems.md)) |
| NVMe | Non-Volatile Memory Express: a fast SSD protocol over PCIe, often in an M.2 slot ([Core 1, Domain 3](core-1/3-hardware.md)) |
| ONT | Optical network terminal: the box that converts a fiber connection for the customer's network |
| PaaS | Platform as a service: the provider runs the OS and runtime; you deploy your code ([Core 1, Domain 4](core-1/4-virtualization-and-cloud-computing.md)) |
| PCIe | Peripheral Component Interconnect Express: the expansion bus for graphics, network and NVMe cards |
| PII | Personally identifiable information: data that can identify a person ([Core 2, Domain 4](core-2/4-operational-procedures.md)) |
| PoE | Power over Ethernet: power and data over the same network cable, for access points, phones and cameras |
| POP3 | Post Office Protocol 3: downloads mail from the server; port 110 |
| POST | Power-on self-test: the firmware's hardware check at startup; failures show as beep codes or messages ([Core 1, Domain 5](core-1/5-hardware-and-network-troubleshooting.md)) |
| PSU | Power supply unit: converts wall AC power to the DC voltages a PC uses |
| PUP | Potentially unwanted program: bundled software such as adware or toolbars |
| PXE | Preboot Execution Environment: booting a computer from the network, often to install an OS |
| RADIUS | Remote Authentication Dial-In User Service: a central AAA server, used for example with WPA2 or WPA3 Enterprise |
| RAID | Redundant array of independent disks. RAID 0 stripes for speed with no redundancy; RAID 1 mirrors; RAID 5 stripes with parity; RAID 10 mirrors and stripes ([Core 1, Domain 3](core-1/3-hardware.md)) |
| RDP | Remote Desktop Protocol: Windows remote desktop access; port 3389 ([Core 2, Domain 4](core-2/4-operational-procedures.md)) |
| RJ45 | The 8-pin connector on twisted-pair Ethernet cable; RJ11 is the smaller telephone connector |
| RMM | Remote monitoring and management: tools a support team uses to watch and manage many endpoints remotely |
| SaaS | Software as a service: complete applications delivered over the internet, such as webmail ([Core 1, Domain 4](core-1/4-virtualization-and-cloud-computing.md)) |
| SATA | Serial ATA: the common interface for 2.5-inch and 3.5-inch drives |
| SDS | Safety data sheet: the document describing a product's hazards and safe handling, such as toner ([Core 2, Domain 4](core-2/4-operational-procedures.md)) |
| SFTP | SSH File Transfer Protocol: encrypted file transfer over SSH, port 22 |
| SMB | Server Message Block: Windows file and printer sharing; port 445 |
| SMTP | Simple Mail Transfer Protocol: sends mail between servers; port 25 |
| SNMP | Simple Network Management Protocol: monitors and manages network devices |
| SODIMM | Small outline DIMM: the smaller RAM module used in laptops ([Core 1, Domain 3](core-1/3-hardware.md)) |
| SOHO | Small office/home office: a small network usually built around one router ([Core 1, Domain 2](core-1/2-networking.md)) |
| SPF | Sender Policy Framework: a DNS TXT record listing the servers allowed to send mail for a domain |
| SSD | Solid-state drive: storage on flash memory, with no moving parts |
| SSH | Secure Shell: encrypted remote command-line access; port 22 |
| SSID | Service set identifier: the name of a wireless network |
| SSO | Single sign-on: one login gives access to several systems |
| TCP | Transmission Control Protocol: connection-oriented, with delivery checks and retransmission ([Core 1, Domain 2](core-1/2-networking.md)) |
| TKIP | Temporal Key Integrity Protocol: the legacy WPA encryption method, now considered insecure |
| TOTP | Time-based one-time password: a short code, usually valid for about 30 seconds, generated by an authenticator app |
| TPM | Trusted Platform Module: a chip that stores encryption keys and supports features such as BitLocker ([Core 2, Domain 2](core-2/2-security.md)) |
| UAC | User Account Control: the Windows prompt that asks for consent or credentials before a change needs admin rights ([Core 2, Domain 2](core-2/2-security.md)) |
| UDP | User Datagram Protocol: connectionless and fast, with no delivery guarantee ([Core 1, Domain 2](core-1/2-networking.md)) |
| UEFI | Unified Extensible Firmware Interface: modern firmware that replaces BIOS and supports Secure Boot and GPT |
| UPnP | Universal Plug and Play: lets devices open router ports automatically; often disabled for security |
| UPS | Uninterruptible power supply: battery backup that keeps equipment running through short outages ([Core 2, Domain 4](core-2/4-operational-procedures.md)) |
| UTM | Unified threat management: one appliance combining firewall, intrusion prevention, filtering and more |
| VDI | Virtual desktop infrastructure: desktops run as VMs in a data center and are reached over the network ([Core 1, Domain 4](core-1/4-virtualization-and-cloud-computing.md)) |
| VLAN | Virtual LAN: splits one physical switch into separate logical networks |
| VM | Virtual machine: a software computer running on a hypervisor |
| VPN | Virtual private network: an encrypted tunnel across an untrusted network |
| WPA2, WPA3 | Wi-Fi Protected Access 2 and 3: wireless security standards. WPA2 uses AES; WPA3 replaces the pre-shared key exchange with SAE (Simultaneous Authentication of Equals) ([Core 2, Domain 2](core-2/2-security.md)) |
| XSS | Cross-site scripting: an attack that injects malicious script into a trusted website (the official list prints it as XXS) |
