# Core 1 (220-1201) overview

Core 1 is the hardware and networking half of CompTIA A+ V15: laptops and phones, cables and connectors, RAM and storage, printers, IP addressing and Wi-Fi, virtual machines and cloud models, and troubleshooting all of it. You need Core 1 and [Core 2 (220-1202)](../core-2/README.md), from the same version, to earn A+. All exam facts here come from CompTIA's Core 1 V15 page and the official 220-1201 objectives. The practice items are original.

## Core 1 at a glance

| Item | Detail |
|---|---|
| Exam code | 220-1201 (A+ Core 1, V15) |
| Launched | March 25, 2025 |
| Retires | Usually three years after launch (CompTIA estimates 2028) |
| Questions | A maximum of 90 |
| Question types | Multiple-choice (single and multiple response), drag-and-drop, performance-based |
| Time | 90 minutes |
| Passing score | 675 on a scale of 100 to 900 |
| Recommended experience | 12 months of hands-on experience in an IT support specialist job role |
| Languages | English, German, Japanese |
| Delivery | Pearson VUE test center, or online with OnVUE |
| Pairs with | Core 2 (220-1202). Both must be from the same version |

The rules that apply to both cores (order, retakes, renewal) are on [How CompTIA A+ works](../a-plus-overview.md).

The weights are CompTIA's. The question counts are our arithmetic (weight times 90, rounded down); CompTIA does not publish how many questions come from each domain, and a real exam can differ.

Two things follow. Hardware and Troubleshooting together are more than half the exam, and the troubleshooting questions reuse everything from Domains 1 to 3, so knowing the hardware well pays twice. Networking at 23% is the most memorization-heavy domain: port numbers, Wi-Fi standards and DNS record types are easy marks once learned and certain misses if not.

## What Core 1 covers

- **Mobile Devices:** replacing laptop and phone parts, accessories and connection options (USB-C, Bluetooth, NFC), and setting up mobile network connectivity and app support.
- **Networking:** TCP and UDP ports and protocols, wireless frequencies and 802.11 standards, server roles and internet appliances, DNS, DHCP and IP addressing, networking hardware, SOHO router setup, internet connection and network types, and networking tools.
- **Hardware:** display types and attributes, cables and connectors, RAM, storage and RAID, motherboards, CPUs and add-on cards, power supplies, and printer setup and maintenance.
- **Virtualization and Cloud Computing:** virtualization concepts such as hypervisors and containers, and cloud concepts such as service and deployment models.
- **Hardware and Network Troubleshooting:** symptom-driven troubleshooting of motherboards, RAM, CPUs and power, drives and RAID, displays and projectors, mobile devices, networks and printers.

## How the Core 1 questions work

- **Symptom first.** Many Domain 5 stems describe what a user sees or hears (grinding noise, no POST, faded prints, limited connectivity) and ask for the most likely cause or the next step. Learn symptoms and causes as pairs.
- **Choose the right part or standard.** Hardware questions often give a requirement (form factor, speed, connector, power) and ask which component fits.
- **PBQs.** Expect tasks such as matching ports to protocols, configuring a SOHO router, or picking cables and connectors. See [performance-based questions](../performance-based-questions.md).
- **Not exhaustive.** The objectives' example lists are the minimum; other examples can appear.

## How to study Core 1

Our suggested order, built on the weights:

1. **Take the [diagnostic](../diagnostic.md)** to find where you already stand.
2. **Start with Domain 3, Hardware (25%).** It is the vocabulary for everything else: RAM types, storage interfaces, RAID levels, connectors, power supplies, printers. Lay out real cables and parts if you have them.
3. **Then Domain 2, Networking (23%).** Write the port table from memory until it is automatic. Practice reading an IP configuration and spotting an APIPA address.
4. **Then Domain 5, Troubleshooting (28%).** It is the heaviest domain, but it is much easier once Domains 2 and 3 are solid. Build a symptom and cause table for each objective, 5.1 to 5.6.
5. **Then Domains 1 and 4 (13% and 11%).** Smaller, but full of definition questions that are quick marks: mobile connectivity, MDM, hypervisor types, cloud service models.
6. **Do the practice items** at the end of each domain page and score yourself honestly.
7. **Finish with timed runs** so about one minute per question feels normal.

If you are new to IT, give each step a week or more. See [study plans](../study-plans.md) for day-by-day versions.
